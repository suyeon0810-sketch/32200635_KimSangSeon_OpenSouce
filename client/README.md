# 노래 코칭 프로그램 웹 클라이언트 - Fixed

## 포함 파일
- index.html
- style.css
- script.js
- assets/original-file-card.png
- assets/user-recording-card.png

## 반영 내용
- 최신 사용자 녹음 파일 이미지 반영
- 최신 원곡 파일 이미지 반영
- 실시간 그래프 범례 유지
- 최종 결과 화면 처음으로 버튼 유지
- 재녹음 후 분석 흐름 반복 구조 유지

## 실행 방법
- index.html 더블클릭
- 또는 터미널에서 폴더로 이동 후 `open index.html`
